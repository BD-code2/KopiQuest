# ☕ KopiQuest — Android Coffee Logo Quiz

**KopiQuest** is a simple Android quiz game where players test their knowledge of popular coffee brands by guessing their logos. Built with Kotlin and Android Studio, this project is part of my journey in learning Android application development.

## ✨ Features

- 🎮 **Coffee Logo Quiz** — Guess the coffee brand based on its logo.
- 🔀 **Randomized Questions** — Questions are selected randomly from the available coffee logo collection.
- 📊 **Score Tracking** — Keep track of your score while playing.
- ⏭️ **Skip Questions** — Skip a question if you don't know the answer.
- 💬 **Answer Feedback** — Receive feedback after submitting an answer.
- ☕ **Coffee-Themed UI** — A warm interface featuring cream, brown, and yellow colors.
- 📖 **About Page** — Learn more about the KopiQuest application.

## 🛠️ Built With

- **Kotlin** — Main programming language.
- **Android Studio** — Development environment.
- **XML Layouts** — User interface design.
- **Android SDK** — Android application framework.

## 🎯 Project Goals

KopiQuest was created as a learning project to practice Android development, including activity navigation, UI design, user input handling, randomized quiz questions, and score management.

## 🚀 Getting Started

To run KopiQuest locally:

1. Clone this repository.

   ```bash
   git clone https://github.com/YOUR-USERNAME/KopiQuest.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Wait for Gradle synchronization to finish.
5. Run the application on an Android emulator or a compatible Android device.

## 📱 Compatibility

- **Minimum Android Version:** Android 7.0 (API 24)
- **Platform:** Android
